# 🎱 局域网台球 · 黑八

一个可在局域网内联机对战的八球(黑八)台球游戏。
**零依赖** —— 只需要安装 [Node.js](https://nodejs.org),无需 `npm install`,整个项目就是几个 JS 文件。

## 功能

- 🎮 双人对战(黑八规则)+ 无限观战席位
- 👑 管理员登录:可随时**重开对局**、**踢出**玩家/观战者(被踢昵称需更换后才能再加入)
- 🖱 鼠标瞄准、拖拽蓄力击球,带幽灵球瞄准辅助线 + 击球点选择(高低杆/左右塞)
- 🌐 服务端权威物理:击球由服务器模拟并广播,双方画面完全同步,还能实时看到对方瞄准
- 📏 完整规则:开球、分色(全色/花色)、犯规判罚(白球落袋/空杆/首碰错误)、自由球、黑八胜负、再来一局轮换开球
- 🔊 真实采样音效(撞球、库边、落袋、胜利),可静音
- 🔌 断线自动重连;玩家掉线时本局结束并等待重新加入

## 快速开始

```bash
node server.js
```

启动后会打印类似:

```
本机:    http://127.0.0.1:3000
局域网:  http://192.168.28.5:3000
```

- 房主在本机浏览器打开 `http://127.0.0.1:3000`
- 把 **局域网地址** 发给同一 WiFi/网线下的朋友,浏览器打开即可加入
- 先进入的坐 1 号位,第二个坐 2 号位,之后的人自动进入观战

## 管理员

- 默认密码 **`admin123`**(可用环境变量修改:`ADMIN_PASSWORD=你的密码 node server.js`),启动时也会打印在控制台。
- 登录页点击「管理员登录」展开密码框,填入密码后正常加入(有座位就入座,没座位就观战,管理权不受影响)。
- 管理员页面右上角出现 👑 按钮,点开管理面板:
  - **重开一局**:任何时刻(含击球中途)重置球台,开球权自动轮换;
  - **踢出**:把玩家或观战者移出房间,对方会看到"已被移出房间"提示,且该昵称在服务器重启前无法再加入(换个昵称即可)。
- 普通玩家发送管理指令会被服务器直接拒绝(有权限校验,前端隐藏按钮只是表现层)。

> 换端口:`PORT=8080 node server.js`(Windows PowerShell:`$env:PORT=8080; node server.js`)
> 改管理员密码:`ADMIN_PASSWORD=你的密码 node server.js`

## 无法访问?

1. **Windows 防火墙**:首次运行时允许 Node.js 访问专用网络;或手动放行:
   控制面板 → Windows Defender 防火墙 → 高级设置 → 入站规则 → 新建端口规则(TCP 3000)。
2. 确认两台设备在同一局域网(路由器下),IP 以 `192.168.` 开头通常没问题。
3. 手机热点下两台设备也可以(用热点分配的 IP)。

## 操作说明

| 操作 | 方式 |
| --- | --- |
| 瞄准 | 移动鼠标(球杆实时跟随,方向锁定后可微调) |
| 蓄力击球 | 在台面**按住并向后拖拽**,力度条显示力量,松手击球 |
| 击球点(高低杆/左右塞) | 底部白色小球上**点击/拖拽蓝点**:点上方=跟杆、下方=拉杆、左右=侧塞,双击复位 |
| 微调角度 | `←` / `→`(配合 `Shift` 更精细) |
| 蓄力(键盘) | 按住 `空格` 蓄力,松开击球 |
| 取消击球 | `Esc` 或把球杆推回原位再松手 |
| 自由球 | 犯规后移动鼠标放置白球(红色圈表示位置无效),点击放置 |

## 规则简述(简化中式黑八)

1. 开球:白球置于开球线后,大力冲散球堆;开球进球不分色,继续击球;开球黑八落袋则放回置球点。
2. 分色:开球后第一次**合法**打进彩球,即按该球确定「全色(1-7)/ 花色(9-15)」。
3. 连击:合法打进本方球则继续击球,否则换对方。
4. 犯规(白球落袋、未击中任何球、首碰非本方球):对方获得**全场自由球**。
5. 胜负:清完本方球后,将黑八(8 号)合法击入任意袋即获胜;**提前**打进黑八或打黑八时犯规,直接判负。

## 技术说明

```
server.js        Node 服务:静态文件 + WebSocket(自实现 RFC6455 精简版)+ 房间/回合/规则 + 60Hz 权威物理
wslib.js         零依赖 WebSocket 服务端实现(握手/帧编解码/心跳)
physics.js       台球物理共享模块(碰撞、库边、袋口、摆球),浏览器与服务端共用
public/          前端(Canvas 渲染、输入、UI、音效)
```

- 物理在**服务端**运算并逐帧广播,客户端只做表现,杜绝两端不一致;
- **真实摩擦 + 完整三维自旋**(依据 Han 2005 事件式台球模拟 / Alciatore 球间摩擦论文):
  - 三相运动:滑动(线性减速+摩擦力矩旋进自然滚动)→ 滚动(滚动阻力)→ 竖轴旋转独立衰减;
  - **击球点系统**:高杆跟进、低杆拉杆回走、左右塞,起手自旋由击球点物理计算(自旋/速度比 = 2.5×偏移,R 上限 0.55);
  - **球间 throw 效应**:球间摩擦让切球时目标球偏离两球连线约 1~3°,并按真实规律把侧旋传递给目标球;
  - **物理库边模型**:法向恢复 + 切向摩擦冲量,侧塞会“咬库”改变反弹角,滚动球撞库会被“吃”掉反弹速度;
- **音效为真实采样**(freesound.org,均 CC0 公有领域):球碰球两种、出杆、落袋、库边撞击;加载时自动截取首次撞击、归一化音量,播放时随机 ±8% 变调避免重复感,音量随撞击速度、声像随球在台面位置变化;采样加载失败自动回退为合成音;
- 瞄准辅助线由客户端本地射线检测计算;
- 调试:`?test=1` 参数可开启 `window.__test` 钩子(强制摆球、代打等),仅用于自动化测试。

| 参数 | 默认 | 含义 |
| --- | --- | --- |
| `MU_SLIDE` | 0.20 | 呢面滑动摩擦系数(真实值 0.15~0.25) |
